# VerbaDraw desktop app — downloads

Installers and update files for the VerbaDraw desktop app (Windows and Linux). The source code is
private; this repository only holds the releases.

**→ Easiest: the [download page](https://verbadraw.vercel.app/download)** picks the right file for
your computer.

Or open the [latest release](https://github.com/Muavia842/verbadraw-desktop-releases/releases) and use
the **Download** table at the top of its notes:

| Your computer | File |
|---|---|
| Windows 10 / 11 | `VerbaDraw-Setup-<version>.exe` |
| Linux (any distro) | `VerbaDraw-<version>.AppImage` |
| Linux (Ubuntu / Debian) | `verbadraw_<version>_amd64.deb` |
| macOS | not available yet |

The `.yml` and `.blockmap` files are for the app's automatic updates — you don't need them.

The Windows installer is not signed yet: Windows shows *"Windows protected your PC"* → **More info →
Run anyway**.
